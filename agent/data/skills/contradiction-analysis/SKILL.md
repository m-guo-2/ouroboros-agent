# 矛盾分析法

一切事物都包含矛盾。分析问题的方法就是找到矛盾，区分主次，集中力量解决主要矛盾。

## 不适用场景

**以下情况不需要调用此 skill：**
- 任务是直接执行性的（如"帮我把这段代码格式化"）—— 没有矛盾，无需分析
- 用户已经明确指定了解决方案，只需要实现 —— 矛盾已由用户解决
- 问题只有一个维度，不存在对立面（如"这个函数的作用是什么"）
- 时间紧急且问题属于已知模式 —— 直接套用已验证方案

## 何时使用

你应该在以下情况调用此 skill：

- 面对一个复杂问题，不知道从哪里下手
- 问题中存在多个对立面或冲突因素
- 需要判断多个问题中哪个最重要、最紧迫
- 试图解决一个问题但总是被其他问题干扰
- 分析某个事物的本质和发展方向

## 方法流程

1. **识别所有矛盾** — 列出当前情境中所有对立的、互相制约的因素对
2. **判定主要矛盾** — 解决了它其他矛盾是否缓解？是其他矛盾的根源？处于当前阶段中心？
3. **分析主要方面** — 矛盾内部哪一面占支配地位，决定事物当前性质和发展方向
4. **区分性质** — 对抗性（根本利益冲突，必须取舍）vs 非对抗性（共同利益下分歧，可协商）
5. **选择方法** — 对抗性→果断决策；非对抗性→讨论求同；技术型→`investigation-first`+`practice-cognition`；资源型→`concentrate-forces`；多维平衡→`overall-planning`
6. **监控转化** — 主次矛盾会互相转化，非对抗性矛盾处理不当可能转为对抗性

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 不做矛盾分析就动手 | 先分析，后行动 |
| 搞一刀切 | 每个矛盾都有其特殊性，具体问题具体分析 |
| 抓不住主要矛盾 | 全局着眼，抓住牛鼻子 |
| 忽视矛盾转化 | 持续监控，动态调整 |
| 把非对抗性矛盾当对抗性处理 | 先判断性质，再选择方法 |

## 操作规程

当本 skill 被触发时，执行以下步骤并**输出结构化的矛盾分析表**：

1. **列矛盾清单**：用 bullet list 列出所有可识别的对立面，格式为 `[A] vs [B]`
2. **判定主要矛盾**：标记一个矛盾为 `⭐ 主要矛盾`，一句话说明理由（"解决了它，[X] 和 [Y] 矛盾随之缓解"）
3. **判断性质**：标注 `对抗性`（必须取舍）或 `非对抗性`（可协商）
4. **选择应对方法**：根据性质选择方法，明确写出"接下来我将……"
5. **设置监控提示**：在末尾加："⚠️ 需监控：[次要矛盾X] 是否上升为主要矛盾"

**输出必须包含以上 5 项，不得只输出分析性文字而不给出结论。**

## 与其他 skill 的关系

- **实践认识论**：矛盾分析得出的结论需要在实践中验证
- **调查研究**：识别矛盾的前提是充分的调查研究
- **集中兵力**：抓住主要矛盾后，集中力量解决它
- **统筹兼顾**：当多对矛盾都需要处理时，需要统筹兼顾
- **批评与自我批评**：矛盾分析也适用于审视自己的工作
