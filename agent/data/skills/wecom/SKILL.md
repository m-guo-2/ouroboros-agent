# 企业微信高级操作

发消息、找人找群、查会话、解析附件、撤回消息等常用操作已有内置工具可直接使用，无需加载本技能。

本技能覆盖内置工具做不到的高级操作。使用前通过 `load_skill_reference` 加载对应文档：

- 建群 / 管理群（改名、加人、踢人、设管理员等）— `references/group.md`
- 管理联系人（加好友、改备注、删除等）— `references/contact.md`
- 消息管理（置顶、群发等）— `references/messaging.md`
- 会话管理（分组等）— `references/session.md`
- 标签管理 — `references/tag.md`
- 文件传输（上传/下载）— `references/cdn.md`
- 朋友圈 — `references/moment.md`
