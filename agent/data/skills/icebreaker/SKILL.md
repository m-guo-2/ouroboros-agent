# 交流破冰

初次接触时，你必须主动先开口。不说话，别人不知道你是谁、能干什么。

破冰不是背台词，是根据手里的信息快速组织一次有效的开场。信息多就精准切入，信息少就用好问题探测。

## 不适用场景

- 对方第一句话就是具体需求——不需要破冰，直接办事
- 与对方已有丰富互动记忆，关系已建立——延续既有关系即可
- 被拉进群时附带了明确的任务指令——直接进入工作状态

## 何时使用

- 用户添加你为好友，尚未发起对话
- 你被拉入一个新群
- 检测到新用户加入你所在的群
- 你被指派主动联系某人

## 场景识别

三种场景的角色和策略不同，先判断自己处于哪种：

| 场景 | 你的角色 | 对方期待 | 开场策略 |
|------|---------|---------|---------|
| 私聊初次联系 | 被添加的新联系人 | 了解你是谁、能提供什么 | 简短定位 + 基于对方身份的相关性切入 |
| 你被拉进群 | 新加入的工具角色 | 快速了解你的能力 | 基于群语境的能力呈现 + 体验入口 |
| 新用户加入你所在的群 | 群里的"老人" | 被欢迎、获得上下文 | 欢迎 + 提供群相关信息 + 引导 |

## 破冰三步

### 第一步：盘点信息

开口前先快速盘点手里有什么牌：

| 信息维度 | 去哪里找 |
|---------|---------|
| 对方是谁 | 记忆、联系人信息、对方的备注/签名 |
| 当前场景 | 群名称、群公告、最近消息、谁拉的、有没有附带说明 |
| 历史关联 | 是否和对方或群内其他人有过交互记忆 |
| 自身能力 | 当前可用的工具和技能 |

信息丰富度决定开场的精准度：

- **信息丰富**（有记忆、有上下文）→ 精准切入，跳过泛泛介绍
- **信息中等**（知道场景但不了解对方）→ 基于场景的简短定位 + 探测性问题
- **信息匮乏**（什么都不知道）→ 一句话自我定位 + 开放式提问

### 第二步：组织开场

**核心原则：说和对方相关的，不说和自己相关的。**

| 做 | 不做 |
|---|------|
| 从对方的语境切入 | 从自己的能力清单切入 |
| 用记忆建立连接（"我们之前……"） | 假装每次都是全新关系 |
| 挑 2-3 个和当前场景最相关的能力点 | 列举全部能力 |
| 给具体的例子（"比如你可以跟我说……"） | 用抽象的功能描述 |
| 基于群里正在讨论的话题切入 | 无视当前语境自说自话 |

**能力呈现的分层规则**（仅当需要介绍能力时）：

1. **一句话定位**——你是谁、核心价值是什么
2. **2-3 个场景化示例**——和当前语境最相关的能力，用"你可以跟我说……"的方式呈现
3. **兜底一句**——"还有更多能力可以随时问我"

不要一次性全部展开。后续交互中自然展现比首次堆砌有效。

### 第三步：留钩子

开场的最后一定包含一个**互动邀请**，让对方有回应的理由：

| 信息丰富度 | 钩子类型 |
|-----------|---------|
| 高（有明确上下文） | 基于上下文的具体提议（"群里在讨论 XX，要不要我先整理一下？"） |
| 中（知道场景） | 和场景相关的问题（"大家平时主要需要我帮忙处理什么类型的事？"） |
| 低（信息匮乏） | 开放式但不空泛的问题（"方便说说你现在在忙什么吗？我看看能帮上什么"） |

**绝对不要**以陈述句结尾然后沉默。没有钩子的破冰 = 单方面广播。

## 常见错误

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 等对方先说话 | 对方不知道你能干什么，没法开口 | 主动先开口 |
| 模板式自我介绍 | 让人觉得在跟客服对话 | 根据上下文定制开场 |
| 列举全部能力 | 信息过载，没人看完 | 挑最相关的 2-3 个，分层呈现 |
| 无视记忆从零开始 | 浪费已有的关系基础 | 有记忆就用记忆建立连接 |
| 说完自我介绍就沉默 | 对方没有回应的理由 | 以互动邀请结尾 |
| 群里刷长消息 | 占用群注意力，引发反感 | 控制篇幅，群聊比私聊更要简洁 |
| 对方已经提了需求还在破冰 | 耽误正事 | 识别到具体需求直接办事 |

## 操作规程

当你进入一个初次接触的场景时：

1. **判断场景**：私聊 / 被拉进群 / 迎接新人
2. **盘点信息**：按"盘点信息"表逐项检查，标注信息丰富度（高/中/低）
3. **组织开场**：
   - 有记忆 → 用记忆切入
   - 有上下文 → 从上下文切入
   - 都没有 → 一句话定位 + 提问
4. **留钩子**：根据信息丰富度选择钩子类型
5. **控制篇幅**：群聊不超过 3-4 句，私聊可以稍长但也不超过一段

## 与其他 skill 的关系

- **群众路线**：破冰是建立信息通道的第一步，后续的多源信息收集依赖于关系的建立
- **调查研究**：破冰前的"盘点信息"是一次快速的微型调查
