# 星火燎原

从小处着手不等于没有前途。关键是建立稳固的"根据地"，而不是四处游击。在正确的条件下，星星之火完全可以发展为燎原之势。

## 不适用场景

**以下情况不需要调用此 skill：**
- 项目已有稳固基础，处于扩展阶段而非从零开始
- 用户已经明确了切入点，只需要执行
- 任务是对现有系统的修改，而非新建
- 已经有充分资源，不需要谨慎起步策略

## 何时使用

你应该在以下情况调用此 skill：

- 从零开始一个新项目/新任务
- 资源极度有限，看起来不可能完成大目标
- 面对宏大目标不知从何下手
- 正在做很多零散的事但没有积累
- 需要用最小的投入验证一个想法的可行性

## 方法流程

1. **评估客观条件** — 需求是否真实（有没有"干柴"）？条件是否允许？方向是否正确？条件不具备→先 `investigation-first`
2. **选定根据地** — 选最有优势的切入点，要能站稳（不是一次性的）且能扩展（向外延伸的路径清晰）
3. **拒绝流寇主义** — 不要"这里做一点那里做一点"。在一个点上深入扎根，每步成果为下步打基础，建立可复用的成果
4. **积小胜为大胜** — 每次扩展一小步，确保站稳后再向外延伸。保持耐心，量变积累到质变需要过程
5. **拒绝两种错误** — 悲观主义（"就这点资源做不了什么"）和冒险主义（"不管了先干起来"）

**根据地四要素**：核心功能可靠、可复用、可扩展、经过验证。

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 觉得力量太小没有意义 | 评估条件，小处着手 |
| 到处出击没有重点（流寇主义） | 选定根据地，深入扎根 |
| 根据地没站稳就急于扩展 | 先站稳再扩展 |
| 不评估条件就盲目行动 | 先评估客观条件 |
| 浅尝辄止不断换方向 | 在一个方向上持续深入 |

## 操作规程

当本 skill 被触发时，**输出根据地选择分析和发展路线图**：

1. **评估客观条件**（先于一切行动）：
   ```
   需求是否真实存在：[是/否/不确定] —— 依据：……
   现有可依托的基础：……
   主要障碍：……
   条件评估：[具备发展条件 / 条件不足，需先创造条件]
   ```
   条件不足 → 先调用 `investigation-first`

2. **选定根据地**：
   ```
   根据地选择：[具体是什么]
   选择理由：
   - 我在这里的优势：……
   - 这里能站稳的证据：……
   - 从这里向外扩展的路径：……
   ```

3. **流寇主义检查**（每次扩展前必须通过）：
   - [ ] 上一个切入点已验证稳固？
   - [ ] 本次扩展从上一个根据地自然延伸？
   - [ ] 新增内容可复用？

4. **发展路线图**（分 3 步，不要规划太远）：
   ```
   第1步：[具体行动] → 成功标志：……
   第2步：[具体行动] → 成功标志：……（在第1步稳固后）
   第3步：[具体行动] → 成功标志：……（在第2步稳固后）
   ```

## 与其他 skill 的关系

- **调查研究**：评估客观条件需要调查研究
- **矛盾分析法**：选择根据地需要分析主要矛盾
- **集中兵力**：在根据地上集中全部力量
- **持久战略**：星火燎原是持久战第一阶段的具体方法
- **实践认识论**：每次扩展都是一轮实践-认识的循环
