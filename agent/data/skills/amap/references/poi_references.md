# POI 搜索 API 参考

## 关键字搜索

**端点**: `GET https://restapi.amap.com/v3/place/text`

### 请求参数

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| key | 是 | API Key | |
| keywords | 二选一 | 搜索关键字（仅支持一个） | `肯德基` |
| types | 二选一 | POI 类型编码，多个用 `\|` 分隔 | `050000\|060000` |
| city | 否 | 城市（中文/citycode/adcode），不填则全国 | `北京` / `110108` |
| citylimit | 否 | `true` 仅返回指定城市数据 | `true` |
| children | 否 | `1` 子 POI 归类到父 POI（需 extensions=all） | `1` |
| offset | 否 | 每页条数，建议 ≤25，默认 20 | `20` |
| page | 否 | 页码，默认 1 | `1` |
| extensions | 否 | `base`(默认) / `all`(含详细信息) | `all` |

### 返回字段 (extensions=base)

```json
{
  "status": "1",
  "count": "468",
  "pois": [{
    "id": "B000A83M61",
    "name": "肯德基(北京站店)",
    "type": "餐饮服务;快餐厅;肯德基",
    "typecode": "050301",
    "address": "毛家湾胡同甲13号",
    "location": "116.427281,39.902798",
    "tel": "010-65288932",
    "pname": "北京市",
    "cityname": "北京市",
    "adname": "东城区",
    "adcode": "110101"
  }]
}
```

extensions=all 额外返回：`photos[]`, `tag`, `business_area`, `indoor_map`, `biz_ext`(评分/成本/营业时间) 等。

## 周边搜索

**端点**: `GET https://restapi.amap.com/v3/place/around`

### 请求参数

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| key | 是 | API Key | |
| location | 是 | 中心点坐标 | `116.397499,39.908722` |
| keywords | 二选一 | 搜索关键字 | `餐厅` |
| types | 二选一 | POI 类型编码 | `050000` |
| radius | 否 | 搜索半径(米)，0~50000，默认 3000 | `1000` |
| sortrule | 否 | 排序：`distance`(距离) / `weight`(综合，默认) | `distance` |
| offset | 否 | 每页条数，建议 ≤25，默认 20 | `20` |
| page | 否 | 页码 | `1` |
| extensions | 否 | `base` / `all` | `base` |

返回格式同关键字搜索，额外包含 `distance` 字段（到中心点距离，单位米）。

## 多边形搜索

**端点**: `GET https://restapi.amap.com/v3/place/polygon`

### 请求参数

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| key | 是 | API Key | |
| polygon | 是 | 多边形顶点坐标（至少 2 个），用 `\|` 分隔 | `116.460988,40.006919\|116.48231,39.996171` |
| keywords | 二选一 | 搜索关键字 | |
| types | 二选一 | POI 类型编码 | |
| offset | 否 | 每页条数 | `20` |
| page | 否 | 页码 | `1` |
| extensions | 否 | `base` / `all` | `base` |
