# 持久战略

面对复杂长期任务，既不急于求成（速胜论），也不畏难放弃（悲观论），而是划分阶段、稳步推进。战略上保持信心，战术上每一步都严谨对待。

## 不适用场景

**以下情况不需要调用此 skill：**
- 任务可以在当前会话内完成 —— 不需要分阶段战略
- 用户只需要一个具体步骤的执行结果
- 问题已经有清晰的解法，只缺执行 —— 用 `concentrate-forces`
- 处于某一阶段的具体执行中，不需要重新评估战略

## 何时使用

你应该在以下情况调用此 skill：

- 面对一个明显需要长时间才能完成的复杂任务
- 当前处于劣势（资源不足、信息不够、能力暂时不足）
- 任务进行中遇到了瓶颈，感到焦虑或想放弃
- 需要规划一个分阶段的推进策略
- 别人催促快速完成，但你判断不可能速成

## 方法流程

1. **客观评估态势** — 我方条件（资源、成果、弱点）+ 任务条件（规模、困难、机遇）。既不夸大困难也不低估困难
2. **拒绝速胜论和悲观论** — "马上搞定"是速胜论，"做不到"是悲观论。正确态度：需要持久努力，但最终可以完成
3. **划分三阶段**：
   - **战略防御**（探索积累）：站稳脚跟，调查研究，允许战略退却
   - **战略相持**（最困难也最关键）：积小胜为大胜，耐心推进，这是转变的枢纽
   - **战略反攻**（突破收获）：条件成熟时果断全面推进
4. **在防御中求进攻** — 战略持久，战术速决。每个具体小任务上集中力量快速完成
5. **识别转折点** — 认识够了？资源到位了？障碍消除了？多个指标同时满足时就是时机
6. **保持主观能动性** — 不被暂时困难压倒，在不利中创造有利

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 急于求成（速胜论） | 承认需要时间，分阶段推进 |
| 遇难放弃（悲观论） | 困难是暂时的，坚持就能胜利 |
| 在困难阶段消极等待 | 困难阶段也要主动出击 |
| 不识别阶段转换 | 持续评估，把握转折时机 |
| 蛮干不退让 | 必要时战略退却保存实力 |

## 操作规程

当本 skill 被触发时，**输出阶段评估表和行动计划**：

1. **判断当前阶段**（必须明确选择一个）：
   - `战略防御期`：目标明确但能力/资源暂时不足
   - `战略相持期`：已有一定基础，正在积累优势
   - `战略反攻期`：条件成熟，可以全面推进

2. **填写阶段评估表**：
   ```
   当前阶段：[战略防御/相持/反攻]
   判断依据：……

   我方优势：……
   我方劣势：……
   关键障碍：……

   本阶段的核心任务（1条）：……
   本阶段的禁止事项：……（防止速胜论或悲观论）

   转入下一阶段的条件：当 [具体条件] 时，转入 [下一阶段]
   ```

3. **在防御/相持期，必须同时给出"局部进攻点"**：哪个具体小问题可以立刻集中力量拿下（→`concentrate-forces`）。

4. **设置阶段检查点**：明确说明"在完成 [具体里程碑] 后，重新调用此 skill 评估阶段"。

## 与其他 skill 的关系

- **矛盾分析法**：评估态势时需要分析主要矛盾
- **集中兵力**：在每个阶段内，集中力量解决主要问题
- **星火燎原**：第一阶段的"建立根据地"与星火燎原相呼应
- **实践认识论**：每个阶段都是一轮实践-认识的循环
- **统筹兼顾**：三个阶段之间的资源分配需要统筹兼顾
