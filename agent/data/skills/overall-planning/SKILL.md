# 统筹兼顾

复杂系统中存在多对辩证关系，不能只顾一头而忽略另一头。正确的方法是识别所有重要的关系对，在它们之间找到动态平衡，最大限度地调动一切积极因素。

## 不适用场景

**以下情况不需要调用此 skill：**
- 只有一个目标维度，不存在需要平衡的对立面
- 用户已经明确了取舍方向（用户决策优先）
- 属于战术执行阶段，大方向已定 —— 用 `concentrate-forces`
- 问题是"必须选一个放弃另一个"的硬性约束，不存在动态平衡的空间

## 何时使用

你应该在以下情况调用此 skill：

- 面对多个相互制约的目标，需要权衡取舍
- 发现优化一个维度时损害了另一个维度
- 系统中存在多种利益相关方，需要协调
- 在速度与质量、深度与广度、短期与长期等对立面之间做选择
- 发现自己正在片面地追求某一个目标

## 方法流程

1. **识别所有辩证关系对** — 速度/质量、深度/广度、短期/长期、简单/灵活、探索/稳定等。根据具体情况识别，不套模板
2. **拒绝片面性** — 审视是否完全忽略了某一方面。这是最常见的错误
3. **寻找动态平衡** — 当前阶段哪一方需要更多关注？条件变化后平衡点是否需要调整？
4. **学习他人教训** — 借鉴类似场景中的失败经验，但不照搬
5. **调动一切积极因素** — 目标不是"各方少一点"的妥协，而是找到让各方都能发挥作用的配置
6. **系统性思考** — 调整一对关系时，检查对其他关系的影响

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 只顾一头（片面性） | 识别所有重要关系，拒绝片面 |
| 固定的折中 | 根据条件动态调整平衡点 |
| 照搬他人方案 | 借鉴但不照搬，结合实际 |
| 调整一处不管全局 | 每次调整检查全局影响 |
| 和稀泥（平均分配） | 找到让各方都发挥作用的最优配置 |

## 操作规程

当本 skill 被触发时，**输出辩证关系全景图和平衡方案**：

1. **识别所有辩证关系对**，格式：
   ```
   当前涉及的辩证关系：
   1. [A] ↔ [B]：目前偏向 [A/B/均衡]，偏向程度：[轻微/明显/严重]
   2. [C] ↔ [D]：目前偏向 [C/D/均衡]，偏向程度：……
   ```

2. **片面性检查**：当前方案是否完全忽略了某一方？是刻意取舍还是无意忽略？

3. **确定当前阶段的平衡点**：
   ```
   [A] vs [B]：当前阶段优先 [A]，但确保 [B] 不低于 [最低限度]
   原因：……
   ```

4. **系统影响检查**：
   ```
   如果加强 [A]，对其他关系的影响：
   - 对 [C] vs [D]：[加剧/缓解/无影响]
   ```

5. **设置失衡预警指标**：
   ```
   如果出现 [具体信号]，说明 [A] vs [B] 已经失衡，需要重新调用此 skill
   ```

## 与其他 skill 的关系

- **矛盾分析法**：识别辩证关系对的过程就是矛盾分析
- **调查研究**：了解各方面的实际情况是统筹兼顾的前提
- **群众路线**：统筹兼顾需要听取各方意见
- **集中兵力**：统筹兼顾决定大方向后，在具体执行点上集中兵力
- **持久战略**：不同阶段的平衡点不同，需要阶段性调整
